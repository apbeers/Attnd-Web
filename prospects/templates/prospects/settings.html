How a run works

1. Web search ({{ model }}, OpenAI's web search tool) for upcoming events in the region within the look-ahead, a few themes per search.

2. For each event not seen before (and not already an Attnd event): read its page plus up to two about / contact / sponsor pages, score the fit and keep the organizer contacts published there. Emails and phone numbers are kept only when they are written on the page they came from.

A run stops after {{ max_minutes }} minutes, at its cap of new events, or when today's AI budget (${{ cap|floatformat:2 }} over all runs, setting PROSPECT_DAILY_SPEND_CAP_USD) is used up. Runs never overlap.

Schedule: {% if conf.schedule_enabled %}on, every {{ conf.interval_days }} day(s){% if next_run %}; next run around {{ next_run|date:"M j, g:i A" }}{% endif %}{% else %}off{% endif %}. Heroku Scheduler's run_scheduled_tasks starts it.
